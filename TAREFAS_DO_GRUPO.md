# Tarefas do grupo

1. Criar a interface front-end da aplicacao, com telas para visualizar as respostas, aplicar filtros e navegar entre as questoes.
2. Simplificar e organizar as queries SQL para deixa-las mais legiveis e faceis de explicar, sem alterar a logica, os filtros nem o resultado final.
3. Testar o projeto com uma base de dados maior, para medir desempenho, estabilidade e possiveis gargalos.
4. Revisar a consistencia dos dados padronizados, conferindo se os CSVs gerados e o banco continuam coerentes.
5. Fazer uma checagem final das respostas, validando se os arquivos em `respostas/` batem com o que cada query realmente calcula.
6. Apoiar a documentacao do projeto, explicando as decisoes de padronizacao, a estrutura das pastas e os criterios usados nas respostas.
